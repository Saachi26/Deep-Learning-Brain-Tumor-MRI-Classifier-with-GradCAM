Generated by `python src/report_metrics.py` (raw numbers in [`metrics.json`](metrics.json)).
All figures below are **measured on the held-out test set** — 1,600 images the model
never saw during training or validation.

## Dataset

## Ablation — what augmented fine-tuning bought

| Metric | Stage 1: `train.py` (baseline) | Stage 2: `augmentedFinetune.py` (final) | Δ |
|---|---|---|---|
| Test accuracy | 93.06% | **95.19%** | **+2.13 pts** |
| Macro F1 | 0.9296 | **0.9509** | +0.0213 |
| ROC-AUC | 0.9923 | **0.9950** | +0.0027 |
| Cohen's κ | 0.9075 | **0.9358** | +0.0283 |
| Misclassified | 111 | **77** | **−34 errors (−30.6%)** |
| glioma recall | 0.7675 | **0.8300** | +0.0625 |
| False positives (healthy flagged) | 3 | **0** | −3 |

Heavy augmentation (flips, ±15° rotation, translation, color jitter) + AdamW weight
decay cut test errors by ~31%.

## Model & training configuration

| Item | Value |
|---|---|
| Architecture | EfficientNet-B0 (`timm`), ImageNet-pretrained |
| Parameters | 4,012,672 (all trainable) |
| Checkpoint size | 16.35 MB |
| Input resolution | 224 × 224 RGB |
| Normalization | ImageNet mean/std |
| Loss | Cross-entropy |
| Optimizer | AdamW |
| Stage 1 | LR 1e-3, 5 epochs, batch 32 |
| Stage 2 | LR 1e-4, weight decay 1e-4, 10 epochs, batch 32 |
| Stage 2 augmentation | RandomHorizontalFlip, RandomRotation(15°), RandomAffine(translate 0.1), ColorJitter(0.2/0.2) |
| Explainability | Grad-CAM on `model.conv_head` |
